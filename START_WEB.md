# 🌐 Start the Web Version

## ✅ Web Server is Running!

The Flask web server is now running in the background.

## 🚀 Access the Application

Open your web browser and go to:

### 📍 **http://localhost:5000**

Or try:

### 📍 **http://127.0.0.1:5000**

## 🎮 What You'll See

1. **Home Page** - Choose your game mode
   - 📖 Learn Mode
   - ⚡ Practice Mode (10 seconds per question)
   - 🏆 Challenge Mode (5 seconds per question)

2. **Learn Mode** - Browse 26 JSL letters
   - Use Previous/Next buttons
   - Click letter buttons to jump
   - Arrow keys work too!

3. **Quiz Modes** - Test your knowledge
   - Timed multiple choice questions
   - Live score tracking
   - Sound effects
   - Results screen at the end

## 🛑 Stop the Server

To stop the web server, press:
- **CTRL + C** in the terminal

## 🔄 Restart the Server

To start the server again:
```bash
python app.py
```

## 🌍 Access from Other Devices

To access from your phone or other computers on the same network:

1. Find your computer's IP address:
   - Windows: `ipconfig` (look for IPv4 Address)
   - Mac/Linux: `ifconfig` or `ip addr`

2. Example IP: `192.168.1.100`

3. On other device, go to: `http://192.168.1.100:5000`
